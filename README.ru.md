# TV Remote for Mac

**Пульт для Apple TV в строке меню Mac.** Стрелки двигают выбор, Return выбирает, Esc возвращает назад. Когда Apple TV открывает экранную клавиатуру, на Mac сама появляется строка ввода: просто печатаешь.

[English version](README.md)

<img src="docs/fork/shortcuts-window.png" width="520" alt="Пульт с подсказками клавиш" />

- Работает через домашнюю сеть, так же как пульт на iPhone. Без облака, аккаунтов и подписок.
- Бесплатно, открытый код.
- Основан на [Itsytv](https://github.com/nickustinov/itsytv-macos) Ника Устинова. Чем отличается, [написано ниже](#чем-отличается-от-itsytv).

## Что умеет

**Пульт**
- Плавающая панель из строки меню: крестовина, «Выбрать», «Назад», TV/Home, пауза, громкость.
- Всё с клавиатуры: стрелки, Return, Esc, Delete, пробел. Зажатая клавиша работает как зажатая кнопка пульта Siri Remote.
- Подсказки клавиш прямо на кнопках и окно «Сочетания клавиш», где любую клавишу можно попробовать и поменять.

**Ввод текста**
- Строка ввода открывается сама, когда на Apple TV активно текстовое поле (поиск, вход в аккаунт, YouTube, Netflix…), и закрывается, когда поле неактивно.
- Текст, уже набранный на ТВ, виден на Mac. Delete стирает по одной букве.
- ↑ и ↓ выходят из строки и сразу управляют ТВ.
- Любая раскладка Mac, включая русскую.

**Остальное**
- «Сейчас играет»: обложка, название, прогресс, управление воспроизведением.
- Все приложения Apple TV сеткой, порядок меняется перетаскиванием.
- Несколько Apple TV, у каждой свой глобальный шорткат.
- Запуск при входе в систему, AppleScript и действие для «Быстрых команд».

## Чем отличается от Itsytv

[Itsytv](https://github.com/nickustinov/itsytv-macos) — исходное приложение, из которого вырос этот проект. Оно продаётся в Mac App Store и бесплатно лежит на GitHub. Этот проект развивается отдельно:

| | Itsytv | TV Remote for Mac |
|---|---|---|
| Клавиатура на Mac, когда ТВ просит ввести текст | открываешь сам через ⌘K | **открывается сама** |
| Текст, уже набранный на ТВ | не виден | **виден, можно править** |
| Выход из строки ввода | ещё раз ⌘K | **↑ / ↓, или строка закрывается вместе с полем на ТВ** |
| Связь после обрыва | может зациклиться или терять нажатия | **переподключается с паузами, нажатия ждут связи** |
| Пульт остался на другом рабочем столе | там и остаётся | **переезжает на текущий** |
| Поиск в Spotlight | «itsytv» | **«пульт», «тв», «remote», «apple tv»** |
| Сборка | два репозитория рядом | **один репозиторий** |
| Реклама других приложений в меню | есть | **нет** |
| Подсказки клавиш, окно сочетаний, свои клавиши, честное удержание | есть с версии 1.8 | есть (появились здесь) |

## Установка

Подписанной сборки для скачивания пока нет, поэтому собираешь сам. Это пара минут.

Нужно: Mac с macOS 14 или новее, Xcode 16 или новее и Apple TV (4-го поколения или новее, tvOS 15+) в той же сети.

```bash
brew install xcodegen
git clone https://github.com/Lemelson/tv-remote-for-mac.git
cd tv-remote-for-mac
DEVELOPMENT_TEAM=<твой Team ID> scripts/install-fork.sh
```

Скрипт собирает Release, кладёт приложение в «Программы» под именем «Apple TV Remote – Пульт ТВ» и запускает его. Team ID есть в Xcode → Settings → Accounts.

Через Xcode: `xcodegen generate`, открыть `itsytv.xcodeproj`, выбрать свою команду в Signing & Capabilities и запустить схему **itsytv**.

## Первое подключение

1. Нажми значок телевизора в строке меню и выбери свою Apple TV.
2. На ТВ появится четырёхзначный код. Введи его на Mac.
3. Готово. Пара хранится в Связке ключей macOS, соединение зашифровано.

## Клавиши

| Клавиша | Apple TV |
|---|---|
| ← ↑ → ↓ | движение |
| Return | выбрать (зажать: контекстное меню) |
| Esc | назад (зажать: главный экран) |
| Delete | TV / Home (зажать: Пункт управления) |
| Пробел | пауза / воспроизведение |
| = / − | громче / тише |
| ⇧⌘M | без звука |
| ⌘K | печатать на Apple TV |
| ⌘F | поиск приложений |
| ⌘W | закрыть пульт |

Любую клавишу можно поменять: меню ⋯ на пульте → «Сочетания клавиш…»

## Скрипты

```bash
osascript -e 'tell application id "com.itsytv.app" to pause'
osascript -e 'tell application id "com.itsytv.app" to play'
```

Есть и действие для «Быстрых команд», которое открывает пульт нужной Apple TV. Удобно повесить на Stream Deck.

## Если что-то не работает

**При подключении на ТВ нет кода.** На Apple TV: Настройки → AirPlay и Apple Home → «Разрешить доступ» → «Всем в этой сети». На время подключения выключи «Требовать пароль». В Настройки → Основные → Ограничения разреши «Настройки AirPlay» и «Подключение приложения Remote».

**Пульт закрывается через пару секунд после подключения.** Та же настройка: «Разрешить доступ» должно быть «Всем в этой сети», а не «Только пользователям этого дома».

**Нет значка в строке меню.** На MacBook с вырезом macOS прячет значки, которые не помещаются. Зажми ⌘ и перетащи лишние значки из строки меню.

**Не меняется громкость.** Mac меняет громкость, только если Apple TV управляет ею через HDMI-CEC (Настройки → Пульты и устройства → Управление громкостью). Инфракрасную громкость умеет только физический пульт.

## Как это устроено

Apple TV понимает два локальных протокола, те же, что использует пульт на iPhone:

- **Companion Link**: кнопки, касания, список приложений и ввод текста. Когда на ТВ активно текстовое поле, приходит событие `_tiStarted` с текущим текстом. Поэтому строка на Mac и открывается сама.
- **MediaRemote через туннель AirPlay**: что играет, обложка, прогресс.

После однократной привязки оба канала шифруются (SRP и ChaCha20-Poly1305). Код протоколов лежит в [`ItsytvCore/`](ItsytvCore), приложение для строки меню в [`itsytv/`](itsytv).
